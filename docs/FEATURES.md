# Feature roadmap

- Dashboard and overview
- Fictional card management
- Simulated deposits, withdrawals, received and sent payments
- Expense tracking
- Editable demo net worth and balance
- Demo network/provider display settings
- Local SQLite persistence
- Searchable transaction history
- Analytics and theme preferences

All financial operations remain local simulations. No real payment rails, bank APIs, card credentials, or real account access are implemented.
